# Huokaing Thara Banking, ISP & Financial Ecosystem

An advanced, responsive, and secure multi-node financial ledger and ISP management ecosystem directed by **Mr. Seng Chhat**. Built with modular JavaScript architecture, persistent local storage, custom CSS dark-mode themes, and live multilingual support (including Khmer and Vietnamese).

## 🌟 Key Features

* **Executive Dashboard**: Unified administrative console for overseeing Huokaing Thara ISP nodes and multi-tier banking transaction logs.
* **Persistent Ledger Engine (`ledger.js`)**: Automatically syncs transaction history, updates liquid capital totals, and saves state using browser `localStorage`.
* **Dynamic Deposit & Withdrawal Modules**: Real-time validation, automatic capital calculation, and row removal/rollback actions.
* **Multilingual Translation Widget**: Powered by Google Translate, supporting English, Khmer (ភាសាខ្មែរ), Vietnamese (Tiếng Việt), and more.
* **Clean Dark-Mode UI (`style.css`)**: Modern, high-performance styling inspired by professional trading and banking interfaces.

## 📂 Project Architecture

The project is structured into modular, decoupled files for ease of maintenance and scalability:

├── index.html                  # Core banking & deposit manager interface
├── seng_chhat_portal.html      # Executive Director control portal for Mr. Seng Chhat
├── style.css                   # Unified system theme and responsive grid layouts
├── seng_chhat_portal.css       # Dedicated stylesheet for the executive portal
├── ledger.js                   # Persistent asset and transaction data engine
├── deposit.js                  # Incoming capital processing module
├── withdrawal.js               # Outgoing debit and row-removal controller
├── translate.js                # Google Translate multi-language integration script
└── withdrawal.png              # System application icon / favicon
